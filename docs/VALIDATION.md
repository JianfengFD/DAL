## 使用边界

这是可游玩的单机首版，采用季度模拟和点击建筑的交互。存档存储于当前浏览器，导出的 JSON 可在其他入口继续；没有服务器云同步。不同城市具有不同资源参数，使用同一套可旋转的校园基础场景。

数值和概率服务于玩法；长期平衡仍可在实际游玩反馈中调整。
