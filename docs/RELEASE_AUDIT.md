- 对 `blender/`、`public/assets/`、`dist/` 与 `docs/media/` 共 37 个文件进行静态字节扫描，未发现实际本机用户路径、临时目录路径或常见访问令牌/私钥标记。清理脚本中的通用路径匹配表达式属于检测规则，不是机器信息。
