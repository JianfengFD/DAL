# 实现说明

by JF_Li@FD & Sol

这是一款前端单机游戏。浏览器本地保存状态，核心模拟不依赖 DOM，可在 Node.js 中执行与验证。

- `src/engine.js`：季度模拟、行动、资源、学历与岗位、人才称号、关系、教学、院系和事件。
- `src/content.js`：架空地理、人物、会议、事件及手册数据。
- `src/main.js`：开局、行动选择、事件、换季、存档与页面控制。
- `src/panels.js`：研究、事务、人脉、生涯、舆图与指南界面。
- `src/world.js`：Three.js 场景、Blender GLB 加载、建筑点击与相机。
- `src/audio.js`：可选 Web Audio 合成音乐与风声。
- `blender/build_scenes.py`：可重建场景、工程保存、GLB 导出及渲染。

## 保存

`localStorage` 中的存档只属于当前浏览器和站点源。浏览器清理数据、更改协议或端口会影响可见存档。导出 JSON 是跨设备备份方式；导入经过引擎校验后再替换本机存档。

## 资源与模型

不依赖远程 CDN、图片或字体。模型和脚本随静态构建一起部署。WebGL 不可用时显示 Blender 渲染图并保留行动入口。

## 部署

Vite 构建输出 `dist/`，使用相对 base，支持普通静态托管。公开源码不包含托管账号配置或访问凭据。下载版通过 Python 标准库启动器仅监听本机；也可把 `dist/` 部署到普通静态托管服务。
