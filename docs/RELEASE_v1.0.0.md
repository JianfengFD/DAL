# DAL v1.0.0 · 大夏学术浮生

by JF_Li@FD & Sol

以虚构“大夏”学界为舞台的季度策略游戏。提出问题、做研究、上讲台、申基金，在院系、人情与理想之间经营一段学术人生。

## 下载与运行

下载附件 **DAL-v1.0.0-portable.zip**，完整解压，安装 Python 3.9+，然后运行系统对应启动器：

- macOS：双击 `macOS.command`。
- Windows：双击 `Windows.bat`。
- Linux：终端运行 `bash Linux.sh`。

也可在解压目录运行 `python3 run_game.py`（Windows 可用 `py -3 run_game.py`）。游玩时保持终端打开，退出服务按 Ctrl+C。无需安装 Node.js 或 Blender。

GitHub 自动生成的 Source code ZIP 是开发源码，不包含 `dist/`；普通玩家请选 portable.zip。
