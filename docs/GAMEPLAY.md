# DAL · 大夏学术浮生玩法指南

by JF_Li@FD & Sol

[返回首页](../README.md) · [下载最新版](https://github.com/JianfengFD/DAL/releases/latest) · [观看中文演示](media/dal-gameplay-zh.mp4)

## 1. 开始一段学术人生

在 [Releases](https://github.com/JianfengFD/DAL/releases/latest) 下载 `DAL-v1.0.0-portable.zip` 玩家包，解压后运行系统对应的启动器。电脑需安装 Python 3.9+，并使用支持 WebGL 的现代浏览器。玩家包已包含 `dist/`；GitHub 绿色 `Code → Download ZIP` 是源码，需要先安装 npm 依赖并构建。详细启动步骤见 [README](../README.md#下载与开始)。

开局可填写姓名、选择研究方向、成长背景和难度。姓名会写入履历与成果；研究方向影响课题内容，并对应不同院系；背景提供不同的初始数值。难度影响初始资源、效率与竞争。

| 起点 | 身份与年龄 | 最先要顾及的事 |
| --- | --- | --- |
| 初入校园 | 18 岁本科生 | 完成课程、建立学识，认识研究过程 |
| 博士围城 | 25 岁博士生 | 学业、论文、毕业与下一份岗位 |
| 青椒当家 | 32 岁讲师 | 新课题、教学、项目与六年聘期 |

三档学界风向为“从容”“寻常”“内卷”。第一次游玩可以选择“从容”熟悉规则，或者用“青椒当家”直接体验科研、课堂和考核同时到来的处境。

## 2. 一季怎么过

一年有春、夏、秋、冬四季，每季 **4 格时间**。多数行动消耗一格；建设课程、筹办论坛等选项会消耗两格，具体费用和条件以操作面板为准。切换已有的当前研究课题不消耗时间。

一个常见季度可以安排研究、写作、教学或行政、休息各一项；这只是帮助理解时间分配，并非固定配方。学业阶段、审稿等待、项目期限和压力状态不同，安排也应不同。

点击“结束本季”会结算收入与生活支出，推进审稿、学生培养、项目期限和考核，并可能收到新事件。可以提前结束季度，剩余时间不会带到下一季。收到来信时，先选择回应，才能继续行动或换季。

## 3. 校园与功能入口

在 3D 校园拖动鼠标可以旋转视角，滚轮可以缩放；点击建筑或底部行动栏选择事务。“全部行动”列出当前可用的完整选项，灰色选项会说明尚缺的条件。

| 页面 | 可以查看和办理什么 |
| --- | --- |
| 校园 | 建筑入口、当季安排与履历手记 |
| 研究 | 在研课题、稿件、论文与研究能力 |
| 事务 → 教学 | 课程质量、教学贡献、学时、满意度与学生 |
| 事务 → 院系 | 所属院系、支持度、同事与评价偏好 |
| 事务 → 行政 | 校内部门、熟悉度与流程负担 |
| 事务 → 基金 | 经费、项目期限与资助体系 |
| 人脉 | 人物关系、会议与合作边界 |
| 生涯 | 学历岗位、下一步条件、人才称号与生活账目 |
| 舆图 | 六城的学校、成本、薪酬和研究环境，以及迁居 |
| 手册 | 操作说明、制度取舍与现实参照 |

右上角可开关环境声景、查看指南、管理存档与设置。音乐和风声由合成器生成，可以随时关闭。

## 4. 先看懂状态，再安排工作

| 状态 | 主要作用 |
| --- | --- |
| 学识 | 研究基础、课程与学位要求、项目论证 |
| 洞察 | 提出问题、原创探索与突破机会 |
| 写作 | 稿件组织、申请书与部分会议门槛 |
| 人脉 | 学术交流与人才评议机会 |
| 声誉 | 同行认可、晋升和人才项目条件 |
| 操守 | 研究可信度、晋升底线与核查风险路线 |
| 压力 / 健康 | 决定能否保持工作效率与长期生活 |
| 院系支持 | 晋升、评价改革与院系职责 |
| 教学口碑 / 质量 / 满意度 | 课程效果、年度考核、育人与教学路线 |
| 流程负担 / 部门熟悉度 | 行政摩擦、材料准备与部分采购条件 |

高压力、低健康会降低效率。持续高压还会在季度结算时损害健康。散步、短假、同事互助与生活安排都有用；不要只在健康危机发生之后才安排休息。

## 5. 从问题到论文

科研的大致流程是：

1. **新立项**：在“推进课题”选择基础问题、原创问题或热点问题。最多同时推进三个未完成的课题。
2. **收集证据**：稳步实验推进较快；追问反常进度较慢，但提高原创性，并可能带来突破；复核与开放数据提高严谨性，减少风险。
3. **开始写作**：研究进度达到 70% 后可以撰写稿件或打磨论证。写作与证据积累需要分别推进。
4. **准备投稿**：研究和写作都到 100% 后，选择合适期刊。更高层次的期刊有更高的研究质量要求，费用和审稿时间也不同。
5. **等待与修订**：审稿通过季度结算推进。拒稿后仍可修改、再投；送审后也可以转向另一项课题。

| 课题路线 | 主要取舍 |
| --- | --- |
| 稳健基础 | 可行性与预算更友好，适合形成第一项完整成果 |
| 原创探索 | 推进较慢，原创性和突破潜力较高 |
| 追逐热点 | 进度较快，也容易遇到同质化与指标压力 |

论文并非只按篇数计价。不同期刊给予不同成果积分，证据质量、严谨性和原创性共同决定最终工作。署名交换或跳过负结果可能制造短期优势，也可能给论文留下核查与撤稿风险。

设备和学生团队可以帮助研究。共享平台机时成本较低；采购设备需要更高预算，并要求一定财务流程熟悉度。请阅读当前选项，而不是在资金不足时先把全部时间投入采购。

## 6. 基金：拿到以后也要结题

“事务 → 基金”查看项目，“办理校内事务 → 科研处”做申报预审，“整理与写作 → 打磨基金申请书”完善下一次申请。准备、前期积累、代表作与研究能力都会参与评审；符合申报资格不保证中选。

| 项目 | 游戏资助额 | 执行期 | 主要阶段 |
| --- | --- | --- | --- |
| 大夏大学生创新训练 | 3 万 | 8 季 | 本科、硕士 |
| 校级探索种子基金 | 12 万 | 8 季 | 博士及以后 |
| 大夏自然基金委 · 青年项目 | 30 万 | 12 季 | 博后及以后，受年龄窗口限制 |
| 大夏自然基金委 · 面上项目 | 60 万 | 16 季 | 正式教师 |
| 大夏科技署 · 重点攻关 | 180 万 | 20 季 | 副教授及以后 |

结题会看项目获批后的新增成果；重点攻关还要求新增学生培养。未按期达到目标，可能获得一次延期；延期后仍未完成，会损害声誉与院系支持，并暂停同类申请。启动经费也有自己的期限，不能只靠入职前的旧论文完成新增任务。

金额单位均为万元，且全部为架空游戏值。**科研经费和个人存款是两本账**：研究可优先使用科研经费；生活、住房和迁居依靠个人钱包。大额项目到账不等于个人生活费充裕。

## 7. 教学与学生

硕士阶段开始可以承担课程助理与答疑；正式教师可以主持课程建设。

| 行动 | 作用与代价 |
| --- | --- |
| 备课、更新讲义 | 改善课程质量、口碑与学生满意度；为后续授课做好准备 |
| 认真讲授 | 完成学时、提高口碑与院系支持；准备充分时反馈更好 |
| 建设课程 | 消耗两格时间，形成课程资源，并提高教学表现 |
| 照本宣科 | 快速完成较多学时，代价是质量和满意度下降 |
| 公益答疑、朋辈辅导 | 各阶段均可帮助后来者，积累教学口碑与声誉 |

正式教师有年度教学任务。年度结算会核对当年学时与学生满意度；做了很多研究，并不会自动免除教学考核。教务处协调可以帮助确认任务与安排。

讲师及以上、有足够经费和名额时，可以招收研究生。学生需要持续指导与支持，会逐步成长并协助研究。认真指导提高进度与满意度；长期忽略或一味催产出会带来不满、风险，甚至转组。学生毕业需要培养时间与进度，不能在招收当季就兑换成毕业人数。

## 8. 院系、同事和校内行政

所在院系有自己的传统与评价偏好。讨论研究、分享方法、同事互助与公共服务会改变支持和共同体氛围；高支持也能帮助推动更均衡的评价。

| 单位 | 主要事务 |
| --- | --- |
| 科研处 | 申报预审、科研合同、项目结题与研究合规 |
| 人事处 | 聘期、晋升、人才支持与待遇档案 |
| 教务处 | 课程、教学工作量与培养任务 |
| 财务处 | 报销、预算、采购和合规 |
| 研究生院 | 培养、学位与招生议题，见学位行动及相关事件 |
| 公共平台与资产处 | 共享机时、设备、空间与安全，见设备行动及相关事件 |

前四个部门有直接的办理选项；研究生院与平台议题也会通过相应行动和事件出现。熟悉流程有实际回报，公共服务也消耗时间并可能增加行政负担。

正式教师可以争取科研教学并重、推动代表作与开放科学，或接受论文与人才指标。前两者需要支持或声誉；指标承诺能更快带来支持，也增加以后维持高产出的压力。达到条件后可以竞聘系主任，获得津贴，也承担持续行政责任。

同事既可能是竞争者，也可能在共享代码、互相读稿或协商课程时成为伙伴。个别人物会随着交流增长互信；同一季重复约谈的收益会减少。公开合作、明确署名和分工，通常比把所有关系当作一次性资源更稳定。

## 9. 升学、晋升与聘期

在“生涯 → 学术生涯”查看**眼下的下一步**，那里逐项列出当前值、目标值以及等待期。学位与岗位不会仅因年龄增长自动变化，需要满足条件后主动申请。

游戏简化的通常路线是：

**本科 → 硕士 → 博士 → 博后 → 助教 → 讲师 → 副教授 → 教授**。

条件较强的博后也可直接竞聘讲师。课程助理、初级职称助教与部分现实高校的助理教授含义不同；游戏岗位序列不代表现实中每个人都必须逐级经过。

前期看学习年限、学业进度与学识，硕博阶段还要求成果。进入教职以后，代表作、教学口碑、声誉、项目、院系支持、学生培养与操守逐步共同参与评价。刚完成一次晋升后会有短暂复核等待期。

青年讲师通常有六年聘期目标。按时晋升副教授可以解除这项压力；优秀教学也可能支持转入教学为主岗位。首次考核未达要求可能获得延长期，延长期后仍未通过可能调整到助教岗位，故事可以继续。

正式教师可以主动选择**教学为主岗位**：科研门槛降低，晋升更重视课堂与学生培养，工资有所降低，聘期压力缓解。这是一条不同评价路线。

## 10. 人才称号与荣誉

称号与职称单独计算。讲师可以拥有青年人才支持，教授也可以没有“帽子”。在行动面板查看每项的成果、声誉、岗位、项目、年龄、操守等具体条件；达到条件后，仍需要经过有机会性的评议。

| 游戏称号 | 个人年津贴 | 一次新增科研支持 | 侧重点 |
| --- | --- | --- | --- |
| 省域青拔 | 3 万 | 20 万 | 早期独立研究 |
| 优青 | 6 万 | 80 万 | 青年学术骨干 |
| 长河学者 | 10 万 | 100 万 | 代表作与育人 |
| 杰青 | 15 万 | 180 万 | 原创成果、独立研究与项目积累 |
| 科技署领军 | 18 万 | 220 万 | 重大任务、突破与团队培养 |
| 院士 | 24 万 | 200 万 | 长期贡献、教授岗位、突破与学生传承 |

当前版本同一时间记录一个最高层次称号；新称号的年津贴替换旧津贴，不把所有称号津贴叠加。未入选需要等待后再申请，具体等待时间在选项中显示。

以上全部是游戏设计。现实自然科学基金现采用青年 A / B / C 类等项目名称，优青、杰青的熟悉叫法在本作中保留。项目资助、岗位薪资、单位配套与荣誉不能简单视为全国统一待遇表，见 [制度参照](SOURCES.md)。

## 11. 会议、四唯与权学交易

院系沙龙、大夏学术年会、寰宇前沿大会和六场具名会议各有费用与收益。可重复研究工作坊能支持方法改进，教学年会能带回课堂资源，产业会议则更贴近应用合作。自行筹办论坛会花费两格时间，并增加组织与行政负担。

四唯把复杂的劳动压成可比较的指标。你可以按既有标准冲刺，也可以争取代表作、开放记录与教学贡献进入评价。改变规则需要条件与时间，拒绝某个不当邀约也可能损失关系。

“权力、人情与边界”以及随机事件包含攀附山头、互换署名、评议默契和违规支出等选择。这些可能带来短期资源，也会降低操守、增加核查风险。后果包括贡献追问、关系索债、财务追缴、撤稿、声誉受损与人才申请受限。公开合作、复核数据与真实记录能帮助降低风险，但不能让已经发生的事自动消失。

## 12. 生活、城市与结局

六座城市提供不同的薪酬、成本、研究环境与合作密度。高薪城市也可能更贵；迁居花费积蓄和时间，部分关系与院系支持需要重新建立。各城使用同一套校园基础场景，城市差异主要体现在学校、叙事与规则参数。

散步与运动不花钱；短假恢复更强但需要预算；勤工助学、助研或公开咨询可增加个人收入，也增加压力。经营关系与家庭、购置住房会影响以后的生活支出。生活资源不能全部换成当季进度：反复透支可能引发健康危机。

获得杰青或教授不会立即强制结束。博士阶段起可选择转向企业研发，55 岁起可申请退休，65 岁会进入退休结算；严重的健康或诚信后果也可能让这一卷提前收束。

结局会结合荣誉、教学、学生、原创突破、操守、健康、积蓄与岗位。有留下重要问题的人，也有被学生记住的老师，以及找到可持续生活的普通学者。院士是可能的目标之一。

## 13. 存档与常见问题

**怎样保存？** 每次行动与换季自动保存。右上角“存档与设置”也可手动保存、导出 JSON 或复制完整存档文本。

**怎样换电脑继续？** 导出 JSON，在另一台电脑启动游戏后导入。导入会替换当前自动存档，可先备份已有进度。

**启动后看不到原来的存档？** 检查浏览器和地址是否改变。浏览器存储按访问来源区分，不同端口也属于不同入口；用导出的 JSON 可继续原进度。

**为何按钮不可用？** 先看选项上的条件提示：可能缺少时间、资金、研究进度、岗位或年龄条件，也可能还在评审冷却期。若有待回应的来信，先完成选择。

**为何研究做完了却不能投稿？** 研究进度与写作进度都需达到 100%。选项还会检查该期刊的条件和可用费用。

**为什么这次申请失败？** 项目和人才评议存在随机性。积累与准备可以改善机会，但不能保证每次中选；失败后的等待时间与后续准备也是玩法的一部分。

**启动器没打开浏览器？** 保持终端开启，复制其中显示的 `http://127.0.0.1:端口/` 地址到浏览器。也可在解压目录直接运行 `python3 run_game.py`，Windows 可用 `py -3 run_game.py`。

**可以不联网游玩吗？** 便携包已附完整构建与场景；装好 Python 和浏览器后，本机启动和游玩不需要账号或远程游戏服务。开发时首次安装 npm 依赖则需要获取依赖包。
