# 制度参照与架空边界

查阅日期：2026-10-16。下列均为官方发布的原始材料。它们仅帮助区分真实的职务、科研项目、荣誉与支持方式；本游戏中的城市、学校、人物、机构事件及全部金额、概率、年龄门槛和晋升条件均为架空玩法设定，不对应任何现实待遇承诺。

## 职务与教学

- [人社部、教育部《关于深化高等学校教师职称制度改革的指导意见》](https://hudong.moe.gov.cn/jyb_xxgk/moe_1777/moe_1779/202101/t20210126_511116.html)，2020 年文件、2021 年发布：一般职称序列为助教、讲师、副教授、教授；部分高校可设置助理教授等职务。文件强调教育教学、代表性成果和高校评价自主权。因此游戏同时模拟教学、科研、院系考核；“助教”岗位与研究生担任课程助理在文案中按语境区分，助教也不等同于助理教授。

## 优青、杰青与项目资金

- [国家自然科学基金委：科学基金资助体系 · 青年科学基金项目（B 类）](https://www.nsfc.gov.cn/p1/2791/2809/120778.html)：支持已有较好成绩的青年学者自主研究，培养学术骨干。
- [国家自然科学基金委：科学基金资助体系 · 青年科学基金项目（A 类）](https://www.nsfc.gov.cn/p1/2791/2809/120779.html)：支持已有突出成绩的青年学者自主研究，培养学术带头人。与 B 类在定位、申请条件和支持方式上不同。
- [《国家自然科学基金青年科学基金项目（B 类）管理办法》](https://www.nsfc.gov.cn/p1/2871/2874/2882/136724.html)，2026-06-01：明确项目管理、评审、计划与资金规则；研究期限为三年。科研项目资金按专门规定管理，并非可以自由支取的个人年薪。
- [国家自然科学基金委：2026 年项目资助期限说明](https://www.nsfc.gov.cn/p1/2961/2962/4090/zzqx.html)：B 类三年、A 类五年。项目期限与学校聘期不是同一概念。
- [2026 年度国家自然科学基金项目指南（上册）](https://www.nsfc.gov.cn/u/cms/www/202601/190844586k0w.pdf)：正式项目名称采用青年科学基金项目 A、B、C 类。游戏为回应用户要求，保留“杰青”“优青”等熟悉的旧称；规则有意简化，没有照搬现实年龄与限项制度。

## 待遇为何不能做成全国统一表

- [南方科技大学 2026 人才招聘说明](https://www.sustech.edu.cn/en/notice/9930.html)：其特定招聘计划区分岗位与薪酬、科研资助、团队、实验办公空间、住房、家属服务等支持。该校个案用于说明支持是多项条件的组合，不能概括所有高校。
- [南方科技大学数学系教师招聘](https://math.sustech.edu.cn/conference/13479.html)：公开页面区分前五年的启动支持、额外研究支持、安家支持与年薪增量，并说明适用条件。这些款项不能简单相加为“所有同级人才的固定年薪”。
- [南方科技大学力学与航空航天工程系博士后招聘个案](https://mae.sustech.edu.cn/job/detail/id/1143.html?cid=40&lang=en-us)，2025-04-08：公告的综合年薪包含地方生活补助，并有聘期和具体计划条件。它只证明博士后支持也有不同构成，不代表现实平均水平。

游戏因此分设个人钱包、科研经费、城市生活费与岗位/项目支持。所有数值由玩法平衡决定。现实的具体合同、地区、学科、岗位、考核、补贴期限与发放条件，均可能使同一头衔的待遇有很大差异。

## 院士与学术责任

- [《中国科学院院士章程》](https://www.cas.cn/xxgkml/zgkxyxb/gzzd/yszc/)，2024 年修订：院士为国家设立的最高学术称号和终身荣誉，承担学术发展、人才培养、咨询评议等责任。游戏将其作为独立荣誉轨道，而非把院士当成教授之后自动晋升的普通岗位。

## 四唯与评价改革

- [科技部等五部门关于清理“四唯”的通知](https://www.most.gov.cn/xxgk/xinxifenlei/fdzdgknr/fgzc/gfxwj/gfxwj2018/201902/t20190213_145084.html)，2018 年：清理唯论文、唯职称、唯学历、唯奖项的评价倾向。
- [教育部办公厅“五唯”专项清理通知](https://www.moe.gov.cn/srcsite/A16/s7062/201811/t20181113_354444.html)，2018-11：进一步涵盖“唯帽子”，强调代表性成果、质量、贡献和影响。

游戏中的指标压力、公开规则与代表作试点取自这些一般制度议题；饭局、人情交换、挂名与评议冲突等事件为原创虚构，不是对来源单位或现实个人的描述。
